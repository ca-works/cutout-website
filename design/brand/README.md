# CutOut brand assets

Official CutOut application icon, copied unchanged from the application repository
(`assets/icon/` in `ca-works/cutout`, supplied by the project owner). Do not redraw or regenerate
it; `scripts/make-icons.mjs` only resizes and, for the Apple touch icon, crops it to the rounded
square and fills the corners with the icon's own navy.
