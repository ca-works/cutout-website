## How the mattes were made

Run on 8 November 2026 on an Apple M1 (16 GB, macOS 27.0.1) with the CutOut 0.1 engine
(development commit `899875b`; its engine sources are byte-identical to the public
release source, ca-works/cutout-app commit `54db95b`), BiRefNet general FP32 (ONNX, pinned 28 July 2024 weights) on the
ONNX Runtime CPU provider:

```bash
cutout-cli bench birefnet-general-fp32.onnx cpu <images> <out>              # *-matte.png (refinement on)
cutout-cli bench birefnet-general-fp32.onnx cpu <images> <out> --no-refine  # *-raw-matte.png
cutout-cli bench birefnet-general-fp16.onnx cpu <images> <out>              # FP16 comparison (not stored)
```

`*-matte.png` is the app's default Best Quality result (cubic upscale + guided-filter refinement).
`*-raw-matte.png` is the same prediction with refinement switched off (cubic upscale only). Each
file is the alpha channel of the engine's RGBA output, saved as 8-bit greyscale.

**Reproducibility check:** the refined mattes produced on 8 November for `golden.jpg` and
`dandelion.jpg` are bit-for-bit identical to the mattes made on 4 November (`../golden-matte.png`,
`../dandelion-matte.png`), and the ground-truth scores for the synthetic scenes equal the
application's published results to four decimal places.

## Measurements from the same run (used on the page)

| | Result |
|---|---|
| Fine strands, refined vs ground truth | IoU 0.9920, MAE 0.0119, edge MAE 0.0612 |
| Fine strands, raw vs ground truth | IoU 0.9564, MAE 0.0140, edge MAE 0.0718 |
| Translucent disc, refined vs ground truth | IoU 0.1047, MAE 0.1557, edge MAE 0.4814 (fails: predicted opaque) |
| Golden retriever, FP16 vs FP32 matte | MAE 0.000008; 0.21 % of pixels differ, by at most 12/255 |
| Dandelion, FP16 vs FP32 matte | MAE 0.000049; 1.25 % of pixels differ, by at most 5/255 |
| Inference time on the CPU (single run each) | FP32 15.4 s (golden), 16.2 s (dandelion); FP16 18.2 s, 18.9 s |

IoU is computed on mattes binarised at 0.5; edge MAE is the mean absolute error in a ±6 px band
around the true boundary.
