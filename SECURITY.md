# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).
Include what you found, how to reproduce it and its impact. You will get an acknowledgement
within a week.

In scope: this website's source, its build and deployment workflows, and anything that could
make the site link to a file that is not the genuine published CutOut release.

For vulnerabilities in the CutOut application itself, use the same private reporting on the
application repository once it is public; until then, report here.
